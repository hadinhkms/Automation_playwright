## 2. Lệnh Cơ Bản (Core Commands)
- **Cài đặt dependencies:** `npm install` (hoặc tương đương)
- **Chạy development:** `npm run dev`
- **Build production:** `npm run build`
- **Chạy kiểm thử:** `npm run test` / `npx playwright test`
- **Lint / Format:** `npm run lint`

## 3. Cấu Trúc Thư Mục Chính (Folder Layout)
```text
src/
├── components/   # UI Components
├── features/     # Feature-based business logic
├── services/     # API Client & External services
├── types/        # TypeScript type definitions
└── utils/        # Shared helper utilities
```
