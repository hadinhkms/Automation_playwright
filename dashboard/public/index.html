📖 Hướng Dẫn Từng Bước Thiết Lập Discord QA Bot & GitHub Actions Step-by-Step Guide

Bước 1: Tạo "Nhân viên ảo" (Bot) trên Discord

Mục đích: Tạo con Bot để sau này tester chỉ cần chat là bot tự động đi chạy test.

Bấm để mở Discord Developer Portal
1.1
Tạo hồ sơ Bot mới:

Bấm vào nút màu xanh ở trên để mở trang Discord -> Nhìn lên góc trên bên phải, bấm nút màu tím "New Application".

Ở ô NAME, gõ tên bot: CarThings QA Bot -> Tích vào ô vuông nhỏ đồng ý điều khoản -> Bấm nút Create.

1.2
Lấy mã chìa khóa của Bot (Token):

Nhìn sang cột menu bên trái, bấm vào chữ "Bot" (có hình con robot).

Ở giữa màn hình, tìm chữ TOKEN -> Bấm nút "Reset Token" -> Bấm xác nhận "Yes, do it!".

Bấm nút "Copy" màu xanh để sao chép mã chìa khóa bí mật.

👉 Quay lại Dashboard này: Dán mã vừa copy vào ô DISCORD BOT TOKEN ở bảng phía trên.
Cực kỳ quan trọng (Bắt buộc): Vẫn ở trang đó, cuộn chuột xuống tìm mục Privileged Gateway Intents -> Gạt công tắc dòng MESSAGE CONTENT INTENT sang màu xanh (ON) -> Bấm nút màu xanh Save Changes ở dưới đáy màn hình. (Nếu quên bước này, bot sẽ bị điếc và không đọc được tin nhắn chat của bạn).
1.3
Mời Bot vào Server Discord của công ty:

Nhìn sang cột menu bên trái, bấm vào "OAuth2" -> chọn "URL Generator".

Tại bảng to SCOPES, tích chọn 1 ô vuông: [x] bot.

Ngay sau đó một bảng BOT PERMISSIONS hiện ra ở dưới, tích chọn 4 ô:

  • Send Messages (Gửi tin nhắn)
  • Read Messages/View Channels (Đọc tin nhắn / Xem kênh)
  • Read Message History (Đọc lịch sử chat)
  • Embed Links (Gửi thẻ báo cáo kết quả)

Cuộn xuống đáy trang, bấm nút Copy ở ô GENERATED URL -> Dán link đó vào tab trình duyệt mới -> Chọn Server Discord của bạn -> Bấm Tiếp tục (Continue) -> Bấm Phê duyệt (Authorize).

✅ Kiểm tra: Mở Discord lên, thấy con bot CarThings QA Bot xuất hiện trong danh sách thành viên là thành công!

Bước 2: Lấy Mã Kênh Chat & Link Nhận Báo Cáo

Mục đích: Chỉ định cho Bot biết nó được nhận lệnh ở kênh nào, và bắn kết quả về kênh nào.

2.1
Bật chế độ lấy mã ID trên Discord:

Mở ứng dụng Discord trên máy tính -> Bấm vào biểu tượng Bánh răng cài đặt (User Settings) ở góc dưới cùng bên trái (cạnh tên tài khoản).

Cuộn menu bên trái xuống tìm mục Nâng cao (Advanced) -> Gạt công tắc dòng Chế độ nhà phát triển (Developer Mode) sang màu xanh (ON) -> Bấm nút X góc trên để đóng cài đặt.

2.2
Lấy mã ID kênh nhận lệnh:

Nhìn vào danh sách kênh bên trái Discord, chuột phải vào kênh bạn muốn chat ra lệnh (ví dụ kênh #qa-automation) -> Chọn dòng cuối cùng: Sao chép ID kênh (Copy Channel ID).

👉 Quay lại Dashboard này: Dán dãy số vừa copy vào ô ALLOWED CHANNEL ID ở bảng phía trên (khoảng 18-19 chữ số).
2.3
Lấy Link Webhook nhận báo cáo kết quả:

Vẫn tại kênh đó (hoặc kênh muốn nhận kết quả), chuột phải vào tên kênh -> Chọn Chỉnh sửa kênh (Edit Channel).

Ở cột menu bên trái, bấm vào Tích hợp (Integrations) -> Bấm vào Webhooks -> Bấm Tạo Webhook mới (New Webhook) -> Bấm nút Sao chép URL Webhook (Copy Webhook URL).

👉 Quay lại Dashboard này: Dán link vừa copy vào ô DISCORD WEBHOOK URL ở thẻ trên cùng -> Bấm nút "✈ Gửi tin nhắn thử" để kiểm tra!

Bước 3: Tạo Mật Khẩu Chạy Test Trên GitHub (GitHub Token)

Mục đích: Cấp quyền cho Bot Discord được phép kích hoạt máy chủ GitHub Actions chạy test.

Bấm để mở cài đặt Token GitHub
3.1
Tạo Token mới:

Bấm vào nút màu xanh ở trên để mở trang GitHub -> Bấm nút Generate new token (góc trên bên phải) -> Chọn dòng Generate new token (classic).

Ở ô Note, gõ tên gợi nhớ: Discord Bot Token -> Ở ô Expiration (Hạn dùng), chọn: No expiration (Không bao giờ hết hạn).

3.2
Tích chọn 2 quyền bắt buộc:

Trong danh sách các ô vuông, bạn chỉ cần tìm và tích chọn đúng 2 ô sau:

  • repo (Tích vào ô to chữ `repo` ngay ở đầu danh sách).
  • workflow (Cuộn xuống tìm dòng chữ `workflow` và tích vào).

Cuộn xuống tận cùng đáy trang, bấm nút màu xanh lá cây Generate token.

Bấm vào biểu tượng 2 ô vuông (Copy) bên cạnh chuỗi ký tự bắt đầu bằng ghp_... để sao chép mã Token.

👉 Quay lại Dashboard này: Dán mã vừa copy vào ô GITHUB PERSONAL TOKEN ở bảng phía trên.

Bước 4: Dán Link Báo Cáo Vào GitHub (Secret)

Mục đích: Cho máy chủ GitHub biết link Discord để sau khi chạy test xong, nó tự động bắn kết quả về kênh chat.

Bấm để mở trang Secrets GitHub
4.1
Tạo Secret mới trên GitHub:

Bấm vào nút màu xanh ở trên -> Nhìn lên góc trên bên phải, bấm nút màu xanh lá "New repository secret".

Điền chính xác 2 ô như sau:

Ô Name (Tên): DISCORD_WEBHOOK_URL (Gõ đúng từng chữ in hoa)
Ô Secret (Giá trị): Dán lại đường link Discord Webhook URL bạn đã copy ở Bước 2.3

Bấm nút màu xanh Add secret để lưu lại. Xong!

Bước 5: Bật Bot & Bắt Đầu Thưởng Thức Thành Quả!

Mục đích: Bật công tắc cho Bot thức dậy và bắt đầu chat ra lệnh trên Discord.

5.1
Lưu cấu hình trên Dashboard:

Kiểm tra các ô thông tin ở bảng phía trên -> Nhìn lên góc trên bên phải trang Dashboard, bấm nút màu xanh "💾 Lưu cấu hình".

5.2
Bật Bot chạy (Chỉ cần làm 1 lần):

Mở cửa sổ dòng lệnh (Terminal hoặc PowerShell) trên máy tính -> Dán nguyên vẹn dòng lệnh sau rồi bấm Enter:

cd D:\_CarThings\discord-qa-bot && node bot.js
✅ Khi thấy màn hình hiện chữ: Ready: CarThings QA Bot là Bot đã chính thức thức dậy và sẵn sàng nhận lệnh!
5.3
Thử chat ra lệnh trên Discord:

Mở kênh chat Discord đã cài đặt ở Bước 2, gõ câu lệnh sau rồi bấm gửi:

@CarThings QA Bot run carthings_site dev

🎉 Kết quả: Bot sẽ trả lời ngay và kích hoạt test trên GitHub. Sau vài phút, thẻ báo cáo kết quả (Pass/Fail) sẽ tự động gửi thẳng về kênh chat cho bạn!
